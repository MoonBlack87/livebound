A released Livebound build is a local Python application with a browser interface. You can run it from a release ZIP or from a Git checkout; both use the same start scripts.

1. [Install and start Livebound]({{< relref "installation.md" >}}).
2. [Complete first-start setup]({{< relref "first-start.md" >}}).
3. Open the Library and scan your configured image folders.
