Eleven vision models, four profiles, five real posts, **220 answers, all of them
printed below**. This is not a leaderboard and it draws no conclusion for you:
it is what these models actually wrote inside this application, so you can read
them and pick one.

## What was measured, and on what

A measurement is worth nothing without the machine it ran on and the day it ran.

| | |
| --- | --- |
| Measured | 2026-09-03 |
| Card | NVIDIA RTX 4060, 8 GB |
| RAM | 15 GiB |
| Ollama | 0.33.2 |
| Settings | `vision_max_side` 768, `max_images` 1 — the shipped defaults |

Each model was loaded once, answered all twenty cells, and was released. An
answer was abandoned after 150 seconds, and a model after two such answers in a
row. Nothing was abandoned: **every model answered every time.**

**Every model saw the same thing: one contact sheet holding every picture of a
post, and nothing else.** No generation prompt was sent — that is what the
application does for a model that can see, and it is why these answers say what
a model recognises rather than what it can paraphrase. In an earlier run the
prompt *was* included: one post shows a jaguar while its prompt says "leopard",
and with the prompt only 2 of 8 models named the animal correctly, without it
6 of 8.

This is a measurement, not a compatibility promise for every machine or a leaderboard. New model versions, runtimes and hardware can change the result.

## The four profiles

The shipped profiles, unchanged. They differ in the system prompt and in how
much room the answer gets — the same eleven models are shown under each one
below.

| Profile | Asks for | Temperature | Answer budget |
| --- | --- | --- | --- |
| Plain | names what is visibly there, no interpretation | 0.35 | 500 tokens |
| Standard | plain, with one pointed hook — the everyday choice | 0.55 | 500 tokens |
| Narrative | reads between the lines: what the pictures imply | 0.85 | 700 tokens |
| Storyteller | a short scene with a before and an after | 0.90 | 900 tokens |

All four ask for at most 7 title words and 7 tags, at `top_p` 0.8 and `top_k` 20.

VRAM is what the model added to the card — `nvidia-smi` read before and after
`start_worker()`, so the desktop's own ~950 MB is not counted against it. It is
blank for the hosted models because at that moment nothing has been loaded yet:
`start_worker()` only asks the server what the model can do, and **Ollama pulls
the weights in on the first generation**. Those models do occupy the card, and by
the end of a run the reading shows 4.4 to 6.7 GB for them — but that is read
after the unload has been asked for and Ollama unloads asynchronously, so it
measures what happened to still be resident, not the model. Reporting it would
need a reading taken between the first generation and the last, which this run
did not take.

The interface asks for one post at a time and releases the model afterwards, so
you pay the load **every time**, and for as many variants as you asked for:

```
cost per post = load + variants × answer
```

With three variants: SmolVLM2 about 18 s, granite about 23 s, Qwen3-VL-4B about
31 s, Gemma-3-12B about 91 s, Qwen3-VL-8B about 125 s.
