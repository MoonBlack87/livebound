The normal Livebound workflow moves from a local image library to a reviewed CivitAI post, then back into a local record of what went live.

```text
image folders
    -> library and metadata review
    -> post preparation
    -> CivitAI draft
    -> scheduled or immediate publication
    -> reconciliation
    -> optional archive move
```

Each area can also be used independently. Start with the [Library]({{< relref "library.md" >}}) if you are new to the application.
